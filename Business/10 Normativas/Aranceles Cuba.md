## Base legal
- Resolución Conjunta MFP-MINCEX 1/2021
- [[goc-2022-ex6 RC 1 2021 aranceles para el comercio exterior 1.pdf]]

## Objetivo
Documento de referencia para:
- clasificación arancelaria
- validación HS Code
- cálculo de derechos aduanales
- análisis de costos de importación
- revisión de nomenclatura NMF

## Uso operativo
Se utiliza para:
- cotizaciones preliminares
- validación de viabilidad de productos
- cálculo estimado CIF + arancel
- revisión previa con agente aduanal
- análisis de margen real

## Riesgos críticos
- HS incorrecto
- clasificación errónea
- subvaloración
- sanciones aduanales
- mercancía retenida
- costos mal calculados
- errores en documentación comercial

## Buenas prácticas
- validar HS con agente aduanal
- contrastar HS con proveedor
- revisar notas explicativas
- confirmar si existen restricciones específicas
- validar impuestos adicionales
- revisar actualizaciones regulatorias

## Flujo recomendado
Producto
→ ficha técnica
→ propuesta HS proveedor
→ validación agente aduanal
→ revisión normativa
→ cálculo costos
→ aprobación operación

## Notas estratégicas
El proveedor chino NO es fuente confiable definitiva para clasificación HS.
La responsabilidad final normalmente recae sobre el importador.

Una clasificación incorrecta puede destruir el margen real de una operación.
